# Events & Conferences Manager

**Level:** Department managers · **Role key:** `events-manager` · [All roles](README.md)

> A pre-made role. The super admin can rename it, change every permission, tile and limit below, clone it, or delete it, all without code.

## Purpose

Sells and runs weddings, conferences, parties and retreats, from enquiry to post-event report, including wristbands.

**Reports to:** [General Manager (GM)](general-manager.md)

**Uses:** Igongo app and web portal

## Home screen tiles

- Enquiries to answer
- Events this week
- Venue calendar
- Deposits due
- Wristbands assigned
- Event tasks overdue

## Approval limits

- Event discounts up to Tier 2.
- Can assign and reset wristband ranges.

## Extra rules

- Confirming an event above Tier 3 value goes to the GM.
- Can switch to the client view at any time to see the app exactly as a guest sees it.
