# Personal Assistant to the GM

**Level:** Supervisors and officers · **Role key:** `personal-assistant` · [All roles](README.md)

> A pre-made role. The super admin can rename it, change every permission, tile and limit below, clone it, or delete it, all without code.

## Purpose

Manages the GM's diary, meetings and correspondence.

**Reports to:** [General Manager (GM)](general-manager.md)

**Uses:** The Igongo app on a phone

## Home screen tiles

- Board meeting papers
- Approvals waiting for me
- Tasks

## Modules, screens and default permissions

Includes everything in the [Every Staff Member (base role)](staff-base.md) role, plus:

| Module | Actions | Data scope |
| --- | --- | --- |
| [Meetings & Minutes](../modules/51-meetings.md) | view, create, edit | Everything |
| [Company Calendar](../modules/53-company-calendar.md) | view, create, edit | Everything |
| [Tasks](../modules/42-tasks.md) | view, create, edit | Everything |
| [Notice Board](../modules/49-notice-board.md) | view, create | Everything |

## Approval limits

- None. This role does not approve anything.

## Extra rules

- Can switch to the client view at any time to see the app exactly as a guest sees it.
