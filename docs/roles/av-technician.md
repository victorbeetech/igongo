# Sound and AV Technician

**Level:** Frontline staff · **Role key:** `av-technician` · [All roles](README.md)

> A pre-made role. The super admin can rename it, change every permission, tile and limit below, clone it, or delete it, all without code.

## Purpose

Runs sound, lights, projectors and microphones for events.

**Reports to:** [Events & Conferences Manager](events-manager.md)

**Uses:** The Igongo app on a phone

## Home screen tiles

- Run sheet today
- Event tasks
- Scan an asset
- Report a fault

## Modules, screens and default permissions

Includes everything in the [Every Staff Member (base role)](staff-base.md) role, plus:

| Module | Actions | Data scope |

| [Events & Conferences](../modules/69-events-conferences.md) | view | Own department |
| [Venues & Equipment Hire](../modules/70-venues-equipment.md) | view, edit | Own department |
| [Asset Register](../modules/41-asset-register.md) | view, edit | Own department |
| [Faults & Maintenance](../modules/40-faults-maintenance.md) | view, create | Own department |

## Approval limits

- None. This role does not approve anything.

## Extra rules

- Can switch to the client view at any time to see the app exactly as a guest sees it.
