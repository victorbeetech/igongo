# Volunteer

**Level:** Frontline staff · **Role key:** `volunteer` · [All roles](README.md)

> A pre-made role. The super admin can rename it, change every permission, tile and limit below, clone it, or delete it, all without code.

## Purpose

A short-term helper with access only to assigned tasks and events.

**Reports to:** [Department Supervisor (template)](department-supervisor.md)

**Uses:** The Igongo app on a phone

## Home screen tiles

- My tasks today
- Notice board

## Modules, screens and default permissions

Includes everything in the [Every Staff Member (base role)](staff-base.md) role, plus:

| Module | Actions | Data scope |
| --- | --- | --- |
| [Tasks](../modules/42-tasks.md) | view, edit | Assigned to them |

## Approval limits

- None. This role does not approve anything.

## Extra rules

- Access ends on the last day of the engagement.
- Can switch to the client view at any time to see the app exactly as a guest sees it.
