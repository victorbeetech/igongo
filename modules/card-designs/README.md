# Card designs (module 16: S16-02 to S16-07)

Card templates drawn by the super admin with brand-only colours, fonts and
logos; card types (print size, corners, chip and how it is protected); the
default template (the black portrait card) and the template each role uses.
Saved as one checked set: every template needs a QR code, every element
must sit on the card, and every role must point to an active template.

Routes at `/api/cards/designs` (see `src/presentation/designs-router.ts`).
Tables: schema `card_designs` (one settings table).
